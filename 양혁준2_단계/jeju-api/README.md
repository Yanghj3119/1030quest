# 제주 역사문화 사이트 (API 버전)

공공데이터 API로 받은 제주 역사문화 장소(위치정보 + 일반정보)를 지도와 카드로 보여 주는 사이트입니다.
브라우저는 `/api/places` 만 호출하고, API 키는 서버 환경변수에서만 읽습니다.

## 실행

1. `.env.example` 을 `.env.local` 로 복사해 값을 채웁니다 (`.env.local`, `.env` 는 git 에 올라가지 않습니다).
   - `JEJU_CULTURE_INFO_KEY`, `JEJU_CULTURE_LOCATION_KEY` : 인증키
   - `JEJU_CULTURE_INFO_URL`, `JEJU_CULTURE_LOCATION_URL` : 각 API 요청주소(키 제외)
2. `node server.js` → http://localhost:3000

## 1. 사이트 구조 (화면 2개)

| 화면 | 파일 | 보여 주는 것 |
|---|---|---|
| 조회 화면 | `public/index.html` | 검색·분류·지역 필터와 정렬, 장소 카드 목록, 지도 핀(필터와 연동), 핀 팝업 요약, 상세 창, 찜한 순서대로 이어지는 나만의 답사 코스(순서 변경·거리·가까운 순 정렬·텍스트 복사) |
| 가족 탐방 화면 | `public/family.html` | 지역·테마·곳 수·아이 나이로 하루 나들이 코스 자동 생성(번호 핀·점선·이동시간), 쉬운 설명 카드, 아이와 함께 읽는 상세 창(가족 대화 질문), 스탬프·배지, 출발 전 체크 |

공통: 서버 `server.js` 가 두 API 를 호출·병합(1시간 캐시)해 `/api/places` 로 내려 줍니다.
데이터를 못 받으면 `public/data/step1-places.json`(1단계 파일 데이터)으로 대신 보여 주고 상단에 **연습 모드**를 표시합니다.

## 2. 사용자 관점 개선점 10가지

처음 쓰는 사용자 입장에서 살펴본 목록입니다. (✅ 4단계에서 적용, ⬜ 아직 안 함)

1. ✅ 데이터를 불러오는 동안 아무 표시가 없고, 실패하면 빈 화면 → "불러오는 중" 표시와 실패 안내(연습 모드)
2. ✅ 카드를 눌렀을 때 지도로 이동할지 상세를 볼지 헷갈림 → 카드에 "상세 보기" 버튼 분리
3. ✅ 검색해도 어디가 맞았는지 안 보임 → 검색어 강조 표시
4. ✅ 검색 결과가 없으면 빈 칸만 보임 → 안내 문구와 "검색·필터 초기화" 버튼
5. ✅ 내 주변에서 가까운 곳을 찾기 어려움 → "내 위치에서 가까운 순" 정렬과 거리 표시
6. ✅ 찜한 순서대로 이으면 길이 꼬임 → 코스 "가까운 순 정렬" 버튼
7. ✅ 만든 코스를 가족에게 보내기 어려움 → 코스 텍스트 복사 버튼
8. ✅ 모바일에서 지도가 목록 아래로 밀려 안 보임 → 목록/지도 전환 탭
9. ✅ 지도 핀이 모두 같은 모양 → 분류별 색상과 범례(범례를 누르면 그 분류만 필터)
10. ✅ 처음 오면 무엇을 눌러야 하는지 모름 → 첫 방문 사용법 안내(닫으면 기억, "사용법" 버튼으로 다시 열기)

## 3. API 대비 (불러오는 중 / 실패 시 연습 모드)

- 시작하면 화면 가운데에 "데이터를 불러오는 중…"이 뜹니다.
- API 가 실패(키 누락·응답 오류·20초 초과)하면 1단계 파일 데이터로 화면을 그리고 노란 배너로 "🛠️ 연습 모드"와 실패 이유를 알려 줍니다. "다시 시도" 로 새로고침할 수 있습니다.
- 키를 비운 서버로 새로고침해도 두 화면 모두 연습 모드로 120건이 정상 표시되는 것을 확인했습니다.
- 파일 데이터까지 못 읽을 때만 오류 안내와 "다시 시도" 버튼이 나옵니다.

## 4. 이번에 고치고 추가한 것

조회 화면(`public/index.html`)에 위 개선점 1~10번을 모두 적용했습니다.

- 카드 "상세 보기" 버튼, 검색어 강조, 결과 없음 안내와 초기화 버튼
- 정렬에 "내 위치에서 가까운 순" 추가 (브라우저 위치 권한 필요, 거부하면 이름순으로 되돌림)
- 코스 패널에 "가까운 순 정렬", "복사" 버튼 추가
- 900px 이하 화면에서 "목록 / 지도·코스" 탭 (카드를 누르면 지도 탭으로 이동)
- 분류별 핀 색상과 범례, 첫 방문 사용법 안내
- 두 화면 공통: 불러오는 중 표시, 실패 시 연습 모드
- 서버가 `.env.local` 도 읽도록 변경

가족 탐방 화면(`public/family.html`)에는 1번(로딩·연습 모드)만 적용했습니다.

## 참고

- 실제 제주 API 요청주소와 응답 필드는 아직 확인하지 못했습니다. 필드명이 CSV 헤더(`장소명`, `위도`, …)와 다르면 `server.js` 의 `merge()` 를 고쳐 주세요.
- API 없이 화면만 볼 때: `JEJU_DATA_SOURCE=csv`, `JEJU_CSV_DIR=<CSV 폴더>`.
